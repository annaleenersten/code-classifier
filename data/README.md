## Data Set Sources

PyCodeVul is a Python vulnerability benchmark dataset used to train and evaluate models on code security issues and bug patterns.

PyTraceBugs is a dataset of Python bug examples and trace-based failures, useful for studying common defects and debugging behavior.

- https://www.kaggle.com/datasets/oulabspring/pycode-vul-a-benchmark-dataset-for-python?resource=download
- https://huggingface.co/datasets/gurudesh/pytracebugs/tree/main
